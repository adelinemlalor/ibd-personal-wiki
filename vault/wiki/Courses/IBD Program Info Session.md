# IBD Program Info Session

Details about the International Business Development Program at Berkeley, including course structure and financial responsibilities.

## Summary

The International Business Development Program (IBD) at Berkeley is an elective course featuring international projects with real-world clients, necessitating remote collaboration and in-country project work. The program includes a structured application and selection process that results in team assignments and overseas project work. This material also details the financial responsibilities related to IBD project travel, outlines requirements for international travel, and provides advice for international students concerning program applications and scholarship restrictions.

## Key points

<!-- wiki:keypoints:start -->
- IBD is an elective course offered to MBAs at Berkeley Haas for 34 years. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=4|IBD Info Session Spring 2026_Slides.pdf p.4]]
- Spring 2026 IBD involves 3 Unit Elective FTMBA Course, remote collaboration with clients from January to early-May, and 2 weeks of project work overseas in late-May. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=6|IBD Info Session Spring 2026_Slides.pdf p.6]]
- The IBD application deadline is Oct 8, and notification of acceptance into the IBD program occurs in late October. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=7|IBD Info Session Spring 2026_Slides.pdf p.7]]
- All enrolled students in the 2026 IBD program will have 333 elective points deducted in the Spring Semester and 80 points deducted in the following Fall Semester. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=16|IBD Info Session Spring 2026_Slides.pdf p.16]]
- IBD projects include case studies, entrepreneurial activities, market research, sustainability plans, strategic business plans, feasibility studies, and financial plans and assessments. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=9|IBD Info Session Spring 2026_Slides.pdf p.9]]
- Costs of student flights and accommodations are covered by IBD and the project clients. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=20|IBD Info Session Spring 2026_Slides.pdf p.20]]
- Students are responsible for their in-country meals and entertainment, as well as visas and vaccinations. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=20|IBD Info Session Spring 2026_Slides.pdf p.20]]
- You are required to enroll in UC Travel Insurance when traveling overseas. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=21|IBD Info Session Spring 2026_Slides.pdf p.21]]
- International students are advised to contact the Berkeley International Office (BIO) before completing an application for IBD to ensure all requirements can be met for international project travel in May. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=22|IBD Info Session Spring 2026_Slides.pdf p.22]]
- If you have received a scholarship, you must review your scholarship guidelines before applying for the IBD program to ensure you are allowed to travel overseas in May as part of a university program such as IBD. — [[raw/IBD Info Session Spring 2026_Slides.pdf#page=23|IBD Info Session Spring 2026_Slides.pdf p.23]]

# IBD Project Travel

Two weeks of in-country project work in May, what IBD covers, and what students must arrange.

## Details by source

<!-- wiki:from:src-ibd-info-session-spring-2026-slides:start -->
### From [[IBD Program Info Session]]
- Overseas travel for 2 weeks in May is a critical part of the IBD academic and project experience; teams work on site in-country May 18–30. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=19|IBD Info Session Spring 2026_Slides.pdf p.19]], [[raw/IBD Info Session Spring 2026_Slides.pdf#page=18|IBD Info Session Spring 2026_Slides.pdf p.18]])
- IBD works with the Berkeley Study Abroad Office to get campus approval for all overseas student travel, and participants sign an IBD Code of Conduct as part of the application. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=19|IBD Info Session Spring 2026_Slides.pdf p.19]])
- If travel is cancelled, students keep working remotely to wrap up the project during those 2 weeks. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=19|IBD Info Session Spring 2026_Slides.pdf p.19]])
- Flights and accommodations are paid by IBD and the project clients; students book flights through UC Travel and pay for in-country meals, entertainment, visas, and vaccinations. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=20|IBD Info Session Spring 2026_Slides.pdf p.20]])
- Students must enroll in UC Travel Insurance; countries may require proof of vaccination to enter or to get an entry visa. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=21|IBD Info Session Spring 2026_Slides.pdf p.21]])
- International students should contact the Berkeley International Office, and scholarship students should check whether their scholarship allows overseas travel, before applying. ([[raw/IBD Info Session Spring 2026_Slides.pdf#page=22|IBD Info Session Spring 2026_Slides.pdf p.22]], [[raw/IBD Info Session Spring 2026_Slides.pdf#page=23|IBD Info Session Spring 2026_Slides.pdf p.23]])
